# Numerical methods to solve ODE in Python
Collection of numerical algorithms to solve linear Ordinary Differential 
Equations (ODEs) and linear Partial Differential Equations (PDEs) in Python. 
This project will be Work in Progress (wiP) for a while.

## ODE

1. Forward Euler method for a linear second-order ODE
2. Forward Euler method for a system of linear second-order ODEs (**WIP**)
3. Finite difference method for the boundary value problem of second order linear 
ODE

    2. Numerov's algorithm for QM problems (**WIP**)
